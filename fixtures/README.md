# Original synthetic fixtures

All `.dxf` files here were generated by `scripts/generate_fixtures.py` with
ezdxf 1.4.4. They contain invented geometry, use no customer data, and have **not
been factory-validated**. No production file has been tested.

The nominally clear rectangles are 40 × 20 in declared millimeter drawing
units. They demonstrate limited metadata and endpoint checks only.

`self_crossing.dxf` is a bow-tie: its endpoint degree-two cycle is insufficient
by itself, and the new segment-interior check correctly reports INTER001.
`intersecting_rectangles.dxf`, `interior_endpoint_contact.dxf` and
`collinear_overlap.dxf` exercise INTER001, INTER002 and INTER003 respectively.
`parallel_disjoint.dxf` has very close parallel lines: no exact crossing is
invented, but endpoint proximity is explicitly warned about.
`tolerance_gap.dxf` contains a 0.0000005 drawing-unit gap at a corner; the offset
endpoint also lies in the neighboring segment's interior, so the actual result
contains TOPO003 and INTER002. No fixture result is manufacturing approval.

`reports/` contains actual analyzer outputs for these fixture bytes. Regenerating
DXF fixtures changes library-generated document metadata and therefore the
source hashes; regenerate reports afterward. Analysis of unchanged bytes is
deterministic.
