# Privacy-safe trial feedback

Copy the template into a message only after removing private details. There is
no public issue tracker yet. Do not attach a real DXF or report: file paths,
layer names, entity handles, coordinates and styles can reveal customer IP.
Filename removal is not full anonymization. Use a fresh invented minimal DXF.

- Tool version (`dxf-preflight --version`):
- Python / ezdxf versions:
- OS / architecture:
- Installation or command used (replace private paths):
- Report schema version / status / rule IDs:
- Expected behavior:
- Observed behavior and exit code:
- Small invented reproduction steps, with no customer geometry:

Trial questions:
1. Did installation and the included demo work without help?
2. Was the eligible drawing subset clear before using a real file locally?
3. Could you locate a finding and interpret incomplete coverage correctly?
4. Which CAD handoff step would this improve, if any?
5. Would you use the report for another handoff, and why?

No upload, telemetry or data collection happens automatically. A report is
local until you choose to share it. Positive trial feedback or synthetic tests
alone are not evidence of willingness to pay or production acceptance.
